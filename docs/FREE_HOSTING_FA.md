# راه‌اندازی رایگان بک‌اند NOVA VPN

این راهنما برای راه‌اندازی اولیه و بدون خرید دامنه نوشته شده است. آدرس رایگان سرویس پس از ساخت، توسط Render به‌صورت خودکار ساخته می‌شود.

## چیزهایی که لازم است

- حساب GitHub که به مخزن `mynovavpnproxy1/HamidHamid` دسترسی دارد.
- یک حساب رایگان Render.
- یک حساب رایگان Neon برای دیتابیس PostgreSQL.

**هیچ دامنه اختصاصی لازم نیست و فعلاً هیچ پلن پولی انتخاب نکن.**

## مرحله اول: ساخت دیتابیس Neon

1. وارد https://neon.com/ شو و با GitHub ثبت‌نام کن.
2. یک پروژه PostgreSQL رایگان بساز.
3. منطقه‌ای نزدیک به Frankfurt انتخاب کن تا با منطقه سرویس Render هماهنگ باشد.
4. در صفحه اتصال، گزینه نمایش connection string را انتخاب و آدرس PostgreSQL را کپی کن.
5. این آدرس محرمانه است؛ آن را در چت یا GitHub قرار نده. فقط در بخش Environment سرویس Render استفاده می‌شود.

## مرحله دوم: ساخت سرویس Render

1. وارد https://render.com/ شو و با همان حساب GitHub وارد شو.
2. در داشبورد Render گزینه **New** و سپس **Blueprint** را بزن.
3. مخزن `mynovavpnproxy1/HamidHamid` را انتخاب کن. اگر نمایش داده نشد، دسترسی Render به همین مخزن را از GitHub تأیید کن.
4. Render فایل `render.yaml` را می‌خواند و سرویس `nova-vpn-api` را تشخیص می‌دهد.
5. برای متغیرهای زیر مقدار وارد کن:
   - `DATABASE_URL`: آدرس PostgreSQL که از Neon کپی کردی.
   - `ADMIN_USERNAME`: یک نام کاربری جدید برای پنل مدیریت.
   - `ADMIN_PASSWORD`: یک رمز جدید و منحصربه‌فرد با حداقل ۱۶ نویسه.
   - `JWT_SECRET`: اگر Render خودش مقدار تصادفی تولید کرد، همان را نگه دار.
6. فقط گزینه Free را انتخاب کن و سرویس را Deploy کن.

## مرحله سوم: بررسی آدرس سرویس

بعد از پایان Deploy، Render یک آدرس شبیه این می‌دهد:

`https://nova-vpn-api.onrender.com`

این فقط نمونه است؛ آدرس واقعی را از داشبورد خودت کپی کن.

دو نشانی را باز کن:

- `https://آدرس-واقعی/health` برای زنده بودن برنامه.
- `https://آدرس-واقعی/ready` برای بررسی ارتباط بک‌اند با دیتابیس.

نشانی دوم باید پاسخ `{"status":"ready"}` بدهد. Render هم همین مسیر `/ready` را برای بررسی سلامت سرویس استفاده می‌کند.

## مرحله چهارم: وصل کردن اپ به بک‌اند

وقتی آدرس واقعی HTTPS آماده شد:

1. در GitHub مخزن NOVA VPN را باز کن.
2. به **Settings → Secrets and variables → Actions → Variables** برو.
3. یک Repository variable بساز:
   - Name: `API_BASE_URL`
   - Value: آدرس HTTPS واقعی Render، بدون اسلش انتهایی.
4. به بخش **Actions** برو و اجرای `NOVA VPN CI` را باز کن. در push بعدی هم خودکار اجرا می‌شود.
5. فقط اگر همه بررسی‌ها موفق شوند، فایل APK به‌عنوان Artifact با نام `nova-vpn-debug-apk` ساخته و بارگذاری می‌شود.

## نکات مهم

- رمز Neon، رمز پنل و JWT Secret را برای هیچ‌کس ارسال نکن.
- پروفایل‌های VPN و کانفیگ‌های واقعی را داخل مخزن GitHub یا APK قرار نمی‌دهیم؛ بعداً از پنل مدیریت امن اضافه می‌شوند.
- Render Free پس از مدتی بی‌استفاده‌بودن می‌خوابد و اولین درخواست ممکن است با تأخیر پاسخ دهد. این تأخیر مربوط به بیدار شدن بک‌اند است، نه سرعت تونل VPN.
- Render و Neon فقط بک‌اند و دیتابیس مدیریتی را میزبانی می‌کنند. ترافیک اینترنت کاربر از سرور VPN عبور می‌کند.
- طرح رایگان محدودیت مصرف و دسترس‌پذیری دارد؛ برای شروع مناسب است، اما تضمین سرویس ۲۴ساعته نیست.
